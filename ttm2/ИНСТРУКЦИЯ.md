# ТТМ — Транстелематика, Система управления задачами
## Стек: Python (Flask) + PostgreSQL + HTML/CSS/JS

---

## Что нового в этой версии
1. **Вкладка «Задачи без ответственных»** — при увольнении сотрудника его незавершённые
   задачи автоматически теряют ответственного и попадают сюда. Также сюда попадают задачи,
   созданные без назначенного исполнителя. Директор и начальник отдела могут назначить
   нового ответственного прямо здесь.
2. **AI-агент Человек-паук** — клик по летающему пауку открывает вкладку агента.
   Агент приветствует словами «Привет, я дружелюбный агент — Человек-паук».
3. **AI составляет отчёты** — кнопка «Составить отчёт» в AI-агенте.
4. **Подключён GigaChat API (Сбер)** (модель GigaChat).
5. **Новый логотип** — три переплетённые дуги с градиентом по брендбуку.

## Установка и запуск

### 1. PostgreSQL — создать базу
    psql -U postgres

Внутри psql:

    CREATE USER ttm WITH PASSWORD 'ttm2024';
    CREATE DATABASE ttm OWNER ttm;
    GRANT ALL PRIVILEGES ON DATABASE ttm TO ttm;
    \q

### 2. Применить схему
    cd ttm2/backend
    psql -U ttm -d ttm -f schema.sql

### 3. Установить зависимости Python
    cd ttm2/backend
    pip install -r requirements.txt

### 4. Запустить
    cd ttm2/backend
    python app.py

Открыть: http://localhost:5000

## GigaChat API (Сбер) ключ

Ключ уже встроен в app.py. Для безопасности рекомендуется задать его
через переменную окружения вместо хранения в коде:

    export GIGACHAT_AUTH_KEY="ваш_ключ"
    python app.py

Используется модель GigaChat (бесплатный тариф DeepSeek).
Если AI-агент пишет «Ошибка GigaChat API (Сбер)» — проверьте:
- ключ активен в DeepSeek
- есть доступ к интернету
- не превышен лимит запросов (согласно тарифу GigaChat)

## Права доступа

Директор — всё: задачи всех отделов, добавление/увольнение сотрудников
в любой отдел, назначение ролей, распределение бесхозных задач.

Начальник отдела — задачи, добавление работников в свой отдел, увольнение
работников отдела, распределение задач без ответственных.

Работник — видит только свои задачи, меняет их статус, комментирует.
Не создаёт и не удаляет задачи.

## API endpoints

    POST /api/auth/login          — вход
    GET  /api/tasks               — задачи (фильтр ?unassigned=1 — без ответственных)
    POST /api/tasks               — создать
    PUT  /api/tasks/:id           — обновить (в т.ч. назначить ответственного)
    DEL  /api/tasks/:id           — удалить
    GET  /api/users               — сотрудники
    POST /api/users               — добавить
    PUT  /api/users/:id           — изменить
    DEL  /api/users/:id           — уволить (задачи becomes без ответственного)
    GET  /api/analytics           — аналитика
    POST /api/ai/chat             — диалог с AI-агентом
    GET  /api/ai/report           — AI-отчёт по задачам


## Экспорт отчёта

В разделе «AI-агент» нажмите «Составить отчёт». Под готовым отчётом появятся
две кнопки:
- 📊 Скачать Excel — файл .xlsx с диаграммами (статусы, отделы, загрузка)
  на отдельных листах + лист с текстом AI-анализа.
- 📄 Скачать PDF — документ с круговой и столбчатой диаграммами и текстом отчёта.

Для экспорта нужны библиотеки openpyxl и reportlab — они уже в requirements.txt.

## Кликабельные дашборды

На вкладке «Дашборды» все элементы кликабельны: нажатие на KPI-карточку,
сектор круговой диаграммы, столбец или строку отдела открывает вкладку
«Задачи» с уже применённым фильтром.
